# Board Accessibility and Readability — v1.32.6

This presentation release increases Board-specific text legibility without changing Board data contracts or behavior. It strengthens the typography hierarchy for board titles, controls, cards, table cells, status labels, Kanban content, dialogs, and the Item Workspace; enlarges frequently used targets; improves secondary-text contrast; and adjusts responsive spacing/wrapping to prevent clipping and overflow at larger text sizes.

The pass remains presentation-focused: Board identifiers, data attributes, RPC names, permissions, persistence, drag/drop behavior, history, selection, animations, and backend schema are unchanged. Responsive tab overflow and forced-colors support are included for better zoom and high-contrast resilience.
