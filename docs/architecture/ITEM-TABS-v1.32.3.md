# Item Workspace tab-state refinement — v1.32.3

v1.32.3 removes the duplicate active underline in the Item Workspace navigation.

## Root cause

Two independent active-state mechanisms were rendered simultaneously:

1. the legacy `.item-panel-tabs button.active::after` underline; and
2. the shared v1.30 `.wm-motion-indicator` generated by `motion-orchestrator.js`.

## Resolution

- The shared moving indicator is the sole selection indicator when `.wm-motion-nav` is active.
- The legacy pseudo-element is suppressed for selected Item Workspace tabs.
- The indicator is inset from the tab edges, positioned three pixels above the navigation divider, and uses a two-pixel rounded stroke.
- Hover, focus-visible, selected, and reduced-motion states remain independent of the underline geometry.
- The neutral divider remains a structural separator and no longer visually collides with the selected indicator.

No routing, Item Workspace state, persistence, permissions, or database contracts are changed.
